{% comment %} Figura statica: un sistema dentro l'Universo. Una freccia verde entra nel sistema: il lavoro L_{U→S} compiuto dall'Universo sul sistema (energia che entra); una freccia rossa esce: il lavoro L_{S→U} compiuto dal sistema sull'Universo (energia che esce). Sotto, la formula L = L_{U→S} − L_{S→U}. Nessun parametro. {% endcomment %}
